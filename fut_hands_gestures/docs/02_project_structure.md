# Project Structure

## What about this step?
in this step it is outlined the structure of ML baseline project developed at Inatel

### Directory Structure

## Description

- **dataset/**: This directory contains all the source code for our project.
  - **external/**: Contains reusable React components.
  - **interim/**: Contains CSS stylesheets.
  - **processed/**: Contains CSS stylesheets.
  - **raw/**: Contains CSS stylesheets.

- **dataset/**: This directory contains all the source code for our project.
  - **01_initial_configuration.md**: Contains reusable React components.
  - **02_project_structure.md**: Contains CSS stylesheets.
  - **03_configure_remote_storage.md**: Contains CSS stylesheets.
  - **raw**: Contains CSS stylesheets.

- **env/**: This directory contains all the source code for our project.
  - **pdia_global_params.yaml**: Contains reusable React components.

- **models/**: This directory contains all the source code for our project.

- **notebooks/**: This directory contains all the source code for our project.

- **reports/**: This directory contains all the source code for our project.
  - **figures/**: Contains reusable React components.
  - **metrics/**: Contains CSS stylesheets.

- **scripts/**: This directory contains all the source code for our project.

- **src/**: This directory contains all the source code for our project.
  - **config/**: Contains reusable React components.
  - **data/**: Contains CSS stylesheets.
  - **features/**: Contains reusable React components.
  - **models/**: Contains reusable React components.
  - **utils/**: Contains reusable React components.
  - **visualization/**: Contains reusable React components.
> **NOTE**: for data, features, models and visualization there is the following structure inside each folder
>    - **config/**: This directory contains all the source code for our project.
>        - **constant/** This directory contains all the source code for our project.
>        - **pdia_folder_params.yaml** This directory contains all the source code for our project.
>    - **modules/**: Contains reusable React components.
>    - **services/**: Contains CSS stylesheets.
>    - **utils/**: Contains reusable React components.

- **test/**: Contains static assets and the main HTML file.

- **.dockerignore**: Contains project documentation.

- **.gitignore**: Contains unit and integration tests.

- **deployment.yaml**: Contains unit and integration tests.

- **docker-compose**: Contains unit and integration tests.

- **Dockerfile**: Contains unit and integration tests.

- **dvc.yaml**: Contains unit and integration tests.

- **Jenkinsfile**: Contains unit and integration tests.

- **README.md**: Contains unit and integration tests.

- **requirements.txt**: Contains unit and integration tests.

- **sonar-project.properties**: Contains unit and integration tests.

- **tox.ini**: Contains unit and integration tests.
